# git.c-system.dk

Siden «Produkter og open source» på https://git.c-system.dk/ – C-Systems open source-projekter og det, vi udvikler.

Almindelig HTML uden byggetrin: `index.html` + skrifttyperne i `fonts/` (Red Hat Display/Text, SIL OFL – licens i `fonts/LICENSE-red-hat.txt`).
GitHub Pages viser `main` direkte. Indtil 26-11-2026 var her en Hugo-skabelon; den ligger i git-historikken.
